# Inventory Sorter 排序顺序表

按当前排序逻辑对 Minecraft 基岩版 1.26.60 物品注册表（1627 个物品）的排序结果。

排序顺序对齐 Java 版一键整理 mod **Inventory Profiles Next** 的默认规则，
即原版**创造模式物品栏**的顺序：

> 建筑方块 → 染色方块 → 自然方块 → 功能方块 → 红石 → 工具与实用物品 → 战斗用品 → 食物与饮品 → 原材料 → 刷怪蛋

每个大类内部按「段落 → 材料（木种 / 颜色 / 石料）→ 形态 → 修饰 → ID」排列：

- 同一种材料挨在一起：木板、楼梯、台阶、栅栏、栅栏门、门、活板门、告示牌依次排列；
- 石料按 石 → 圆石 → 花岗岩 → 闪长岩 → 安山岩 → 深板岩 → …… 的固定顺序，每种材料内部按 基础块 → 楼梯 → 台阶 → 墙 → 砖；
- 羊毛、混凝土、陶瓦等按 白 → 橙 → 品红 → 淡蓝 → …… → 黑的固定 16 色顺序；
- 铜制建材按 普通 → 斑驳 → 风化 → 氧化 → 打蜡 的氧化阶段排列。
